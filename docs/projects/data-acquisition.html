Where the Light Is 🎸

John Mayer has long been my favorite music artist!! from his tasteful guitar solos to his beautiful songwriting and vocal depth. I’ve been to a few of his concerts, and he always manages to choose a setlist that is unique while still makes sure we get all the hits. I wondered how those setlists stacked up against each other. That led to my motivating question:

What can I learn about how John Mayer builds his concert setlists?

Below, I walk through how I acquired the data and highlight the most interesting findings from my exploratory data analysis.

Data Acquisition

To build the dataset I wanted, I pulled from multiple online sources.

Primary API used

  • Setlist.fm API — provided detailed information about each concert, including:
    • venue
    • city
    • tour
    • date
    • complete setlist
    • encore structure

Secondary API (attempted)

I originally planned to also integrate: - Spotify Web API — for audio features like tempo, energy, valence, etc.

Although I was able to access the api for Spotify, integrating the features cleanly took more time and effort than expected, so I proceeded with Setlist.fm alone for this version. My GitHub repo still includes the partial Spotify integration work. In a future project, I want to return to this analysis and add in those spotify features.

Growth of Unique Songs Per Concert over time

How quickly does John’s live catalog grow? This line chart shows when each song first appeared and how his total number of unique songs increased over time.

Code 
# Drop missing dates
df2 = df.dropna(subset=["show_date"]).copy()

# Sort chronologically
df2 = df2.sort_values("show_date")

# Identify when each song FIRST appeared
first_plays = df2.groupby("song")["show_date"].min().sort_values()

# Create cumulative count over time
first_plays_df = (
    first_plays
    .reset_index()
    .rename(columns={"show_date": "first_play_date"})
    .sort_values("first_play_date")
)

first_plays_df["cumulative_unique_songs"] = range(1, len(first_plays_df) + 1)

# Plot
plt.figure(figsize=(10, 6))
plt.plot(first_plays_df["first_play_date"],
         first_plays_df["cumulative_unique_songs"],
         marker="o", markersize=3, linewidth=1)

plt.xlabel("Date")
plt.ylabel("Cumulative Unique Songs")
plt.title("Growth of John Mayer’s Live Song Catalog Over Time")
plt.grid(True, linestyle="--", alpha=0.5)
plt.tight_layout()
plt.show()

import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("final_setlists_john_mayer.csv", parse_dates=["show_date"])

song_name = "In Your Atmosphere"   # you can change this to any song

df_song = df[df["song"] == song_name].dropna(subset=["show_date"])
df_song = df_song.sort_values("show_date")

plt.figure(figsize=(9, 5))
plt.plot(df_song["show_date"], range(1, len(df_song)+1), marker="o")

plt.ylabel("Cumulative Plays")
plt.title(f"Cumulative Live Performances of '{song_name}' Over Time")

### Song Popularity Over Time

```{python}
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("final_setlists_john_mayer.csv", parse_dates=["show_date"])

song_name = "In Your Atmosphere"   # you can change this to any song

df_song = df[df["song"] == song_name].dropna(subset=["show_date"])
df_song = df_song.sort_values("show_date")

plt.figure(figsize=(9, 5))
plt.plot(df_song["show_date"], range(1, len(df_song)+1), marker="o")
plt.xlabel("Date")
plt.ylabel("Cumulative Plays")
plt.title(f"Cumulative Live Performances of '{song_name}' Over Time")
plt.grid(True, linestyle="--", alpha=0.5)
plt.tight_layout()
plt.show()
```
